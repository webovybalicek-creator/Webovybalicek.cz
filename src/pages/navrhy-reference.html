Reference

Každý web v okně nejdřív „postaví“ roj kurzorů: kreslí bloky, píše nadpisy, skládá fotky. Hotový web se pak sám pomalu posouvá a myší nad oknem ho projedete sami. Kliknutí otevře živý web.

1 – Pruh hned pod úvodem

Místo statických obrázků živá okna. Pruh přetéká do stran, takže je hned vidět, že webů je víc. Posouvá se šipkami, trackpadem nebo prstem.
